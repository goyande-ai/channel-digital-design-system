# Cover Backgrounds

## cover-background-geometric.png

Pale overlapping triangles in pink, white and blue-grey, 2048 x 1152, with transparency.

**Use:**
- Cover slide only, full width
- Positioned from 36px below the top edge to the bottom
- Over a `grey-pale` fill

**Text over background:**
- `grey` at 20px bold or larger
- `red-dark`
